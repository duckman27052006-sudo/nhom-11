Gửi file tới
máy chủ TFTP.

Kết nối cùng Wi-Fi với máy chủ, nhập địa chỉ cổng upload nội bộ để tiếp tục.

Ví dụ: http://192.168.1.10:8080. Địa chỉ này do người quản lý máy chủ cung cấp.

Địa chỉ đã lưu trên trình duyệt này

Trước khi gửi

  1. Thiết bị phải kết nối cùng mạng Wi-Fi với máy chủ.
  2. Nhập địa chỉ LAN của cổng upload rồi mở trang đó.
  3. Chọn file và gửi. Máy chủ chuyển file tới TFTP qua WRQ.

Trang GitHub này chỉ giúp mở đúng địa chỉ trong LAN. Nó không nhận hay tải file lên GitHub. File chỉ được gửi tới máy chủ khi thiết bị truy cập được cổng LAN.
